# GitHub input mode

The foundation implementation is now included. See [github-acpx.md](github-acpx.md) for its exact commands, binding and validation scope.

Production Issue comments, Project state writeback, report hosting, and production executor ownership remain incomplete or unconfigured. Reports have local paths and no network URL. The observed implementation did not start a real Project event loop.

Do not confuse input detection or completion of a coordinator turn with completion of an Issue. The target final result is a concise Issue conclusion, concrete evidence, and a reader-accessible HTML details link. Legacy local-file and native-hook workflows remain optional.
